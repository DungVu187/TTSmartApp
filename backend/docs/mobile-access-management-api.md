# API Contract Redirect

Contract chính thức của phân hệ User + RBAC nằm tại:

- `docs/RBAC_API_CONTRACT.md`
- `docs/RBAC_PERMISSION_MATRIX.md`
- `docs/RBAC_SCHEMA_MAPPING.md`

Contract hiện tại dùng năm bảng web `User`, `Role`, `UserRole`, `Function`, `FunctionRole` và ActiveKey 9 quyền. Tài liệu cũ về Guid, Right hoặc ActiveRight 6 bit không còn được dùng.
